03 / MENTAL MODEL

Progressive evidence, not bulk retrieval

choose a goal → smallest useful retrieval → check freshness → inspect evidence → deepen deliberately
  • Processed context is orientation, not raw evidence.
  • Relevance is not recency.
  • Generated summaries, bullets and briefs are derived analysis.
  • Hard maxima are safety ceilings, not recommended sizes.
  • TOON is the normal inspection format; JSON is for typed/programmatic work.
  • Article and research retrieval are deliberately progressive.
04 / WORKFLOWS

Use Darth Feedor by question

What is happening now?

get_squawk_context(mode="latest", view="dashboard", format="toon") → inspect age/freshness → narrow the view if needed → validate time-sensitive claims with get_squawks

Was a topic present in recent flow?

get_squawks(hours_back=2, query="CPI OR inflation", limit=20) no match? same window + synonyms → wider window if justified → paginate when needed

Research an article theme

list_articles(query="Treasury curve", limit=10) → get_article_bullets(ids=[...]) → get_article_detail(article_id=<best-id>) → article_graph(article_id=<seed-id>) when related coverage helps → progressive_article_search(seed_query="Treasury curve") for bounded breadth

Build a bounded cross-article brief

Add institutional research

get_research(query="Treasury term premium", limit=10, view="metadata") → inspect publisher/date/tags → get_research_detail(document_id=<selected-id>)

tool_health_check

tool_health_check() -> dict[str, str]

Takes no parameters.

Exact tool description as published to clients
Check availability of the Feedor MCP server and its database connection. Diagnostic probe only — returns no market intelligence. Use when calls fail or to verify server availability before a long workflow. A healthy result is a point-in-time availability status, not a freshness signal for any data surface. If healthy, proceed to the smallest relevant retrieval tool or get_capability_guide for workflow guidance; if unhealthy, no intelligence tool will succeed.

08 / EFFICIENT RETRIEVAL

Save context by default

  • Start lists/searches around 10–25 items.
  • Use the narrowest relevant window.
  • Prefer TOON for inspection; JSON for typed processing.
  • Expand one dimension at a time.
  • Open full detail only after selection.
Hard maxima are safety ceilings, not targets.

Adaptive multi-row surfaces can return explicit partial pages: list/search bullets, selected bullets, article graph, progressive search, context history and research discovery. JSON and TOON are bounded independently and can fit different row counts.

09 / ERRORS & LIMITS

Structured failure, bounded recovery

Invalid scope, unsupported combinations, hard-limit violations and non-adaptive overflows reject structurally rather than silently changing the request.

These ceilings apply before MCP transport framing. The wire envelope is larger. TOON is compact inspection format; request JSON when typed composite processing matters.

13 / KNOWN LIMITS

What this guide does not hide

  • Squawk search is lexical, not semantic.
  • Search-ranked article results are not necessarily recent-first.
  • Generated analysis is derived, not verbatim source text.
  • TOON is not typed composite serialization.
  • Pathological deep reads can still reject after field bounding.
  • Exact continuation is not claimed where relevance/tie ordering cannot be preserved safely.
  • Service health is not intelligence freshness.
